# tecyfyai Homebrew tap

Homebrew formulae for [tecyfyai](https://github.com/tecyfyai) tools.

| Formula | What it does | Install |
| --- | --- | --- |
| [`llm-vitals`](https://github.com/tecyfyai/llm-vitals) | Live tokens per second, cache and context for Claude Code and Codex | `brew install tecyfyai/tap/llm-vitals` |

`brew install tecyfyai/tap/<formula>` adds this tap and trusts only that formula. New releases arrive with `brew upgrade`; a daily workflow opens a pull request when a new version is published.
